How this works. Four tiers, ten weekly waypoints, roughly one per week — but there's no lock and no clock. Each waypoint has a short idea, a work application, a home application, and one real exercise to run with Claude that same week, using something already on your plate rather than a hypothetical.

Why this split. The work/home blend was built from what's already tracked about your projects rather than planned in advance — tiers I–III alternate between the two deliberately, since the same capability (context, building, automation) applies to both. Tier IV leans work, because teaching is where a forensics trainer's advantage compounds fastest.

Progress is saved in this browser — check off an exercise once you've actually run it, not once you've read about it.

Ask Like an Analyst

Not started

The Long Game

What sustains the edge after Week 10

Ten weeks builds the capability. These are the habits that keep it compounding for the next decade instead of decaying back to where you started.

Keep the Case File Current

Periodically review what Claude remembers about your projects. Prune what's stale, correct what's wrong. A file you never audit slowly stops being trustworthy.

Verify Before You Trust

Especially anything evidentiary, legal, or financial. Treat AI output as a lead, not a conclusion — the same way you'd treat an unconfirmed forensic artifact.

Never Solve It Twice

The moment you notice yourself doing something a second time, that's the signal to turn it into a skill or a scheduled task.

Teach What You Learn

Every capability built here gets stronger the moment it becomes training material for someone else — that's the actual compounding part.
