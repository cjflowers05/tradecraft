The Confidence Ladder

A parallel to the tiered AI-confidence model you're building into Azimuth, adapted here for your own use — swap in your actual tier language any time. Each tier below names the range you should be operating in by the time you finish it. The point was never to trust AI output more; it's to know exactly how much you've earned the right to.

L0
Unverified

A claim exists. You haven't checked it against anything.

L1
Cross-Checked

Verified against a primary source, at least once, for this exact claim.

L2
Pattern-Trusted

Seen this class of task done right enough times that a spot-check is enough.

L3
Delegated

It runs on its own; you review for red flags, not from scratch.

L4
Taught

Reliable enough that you've handed it to someone else — a student, Ethan.

WK 01

Build Your Case File

Not started ›
ObjectiveBy the end of this week, one project's context is corrected and trustworthy instead of assumed.
Day 1 — Read

Persistent memory means Claude already knows the terrain going in — but only if what it remembers is actually accurate. An uncorrected file is worse than no file, because it looks trustworthy without being trustworthy.

Day 2 — Try

Paste this in and see what comes back:

Summarize everything you currently know about [pick one: Operation: Laughing GAs / Azimuth / DFS-550]. Flag anything that seems outdated, missing, or wrong.
Day 3 — Apply
At Work

Do it for a live casework or training-content thread.

At Home

Do it for Ethan's application timeline or the backyard build.

Checkpoint

You can name one thing Claude had wrong, and confirm it's fixed now.

Not started ›

The Long Game

What sustains the edge after Week 10

Ten weeks builds the capability. These are the habits that keep it compounding for the next decade instead of decaying back to where you started.

Keep the Case File Current

Periodically review what Claude remembers about your projects. Prune what's stale, correct what's wrong.

Verify Before You Trust

Especially anything evidentiary, legal, or financial. Treat AI output as a lead, not a conclusion.

Never Solve It Twice

The moment you notice yourself doing something a second time, turn it into a skill or a scheduled task.

Teach What You Learn

Every capability built here gets stronger the moment it becomes training material for someone else.
